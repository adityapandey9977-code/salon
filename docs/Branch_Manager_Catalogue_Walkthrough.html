2. Business Rationale & Why We Implemented Everything

Every component, modal input, and metric in the Catalogue Management module directly addresses high-impact operational friction points encountered in multi-location salon and spa chains:

  • Dedicated Catalogue Navbar Navigation for Branch Managers: Front-desk operations and shift managers frequently need to consult exact service procedures, buffer cushions, patch test mandates, and pricing tariffs during day-to-day appointments and walk-in intake. Having "Catalogue" directly in the top navbar provides instant 1-click access without digging through settings.
  • Read-Only Governance Protection: Brand consistency across multi-unit franchise chains relies on centralized service definitions. If individual branch managers could modify base prices, alter tax rates, or delete core services, pricing discrepancies and brand dilution would occur. Read-only view preserves HQ central authority while empowering branch managers with full operational visibility.
  • Branch-Specific Scoping (All Branches + Assigned Branch): Salons often have branch-exclusive treatments (e.g., specialized laser therapies available only at flagship suites). Showing irrelevant services from distant regional branches causes frontline confusion. Scoping the catalogue to services created for "all branches" or "that particular branch" delivers a tailored, noise-free experience.
  • Buffer Timing Envelopes (Pre & Post Service): Without buffer minutes, appointment calendars stack back-to-back, causing severe salon floor delays when hair washing, station sanitization, or dye mixing take extra time. Buffers automate station turnover.
  • Physical Asset Locking (Rooms, Chairs, Equipment): Multi-stylist conflicts frequently happen when two aesthetic therapists book HydraFacial machine sessions or the single private bridal suite at the exact same hour. The Physical Resource Allocation Registry eliminates scheduling collisions at the database layer.
  • Export Utility for Local Operations: Branch Managers can export service menus and tariffs as CSV/spreadsheets using standard purple outline export buttons to print treatment menus or share price references with receptionists.

3. UI Architecture & Page Flow

The master module page (CatalogueMasterPage.tsx) hosts a responsive 5-tab scroll navigation bar with live status pills and header metric counters:

  • Top Navigation Bar: Directly displays Catalogue in desktop center navigation and in the mobile drawer with a distinct View Only pill indicator.
  • Tab 1: Service Categories: Department listing table showing total services, display sort order, status badges, and an Eye icon action button to inspect department dossiers without edit/delete controls.
  • Tab 2: Services Menu: Filterable by category, status, and branch. Exclusively renders services published by Admin for all branches or the manager's assigned branch. Action column features full specification viewing modal covering durations, buffers, required staff skills, and BOM consumable recipes.
  • Tab 3: Service Pricing: Cross-branch comparison matrix showing computed price difference badges (+₹400, -₹200, 0.0% Equal) and detailed breakdown modal.
  • Tab 4: Staff Skills & Levels: Competency tier cards, certification prerequisites, and stylist certification rosters.
  • Tab 5: Salon Resources: Physical room, chair, and device allocation registry scoped to the branch location.
Database Compliance Notice
All data operations respect the Database-Per-Service mandate. Catalogue services, prices, and categories persist exclusively to commerce_db. Branch resources and physical locations persist exclusively to organization_db. All requests are authenticated and scoped via the API Gateway using JWT tenant claims.
