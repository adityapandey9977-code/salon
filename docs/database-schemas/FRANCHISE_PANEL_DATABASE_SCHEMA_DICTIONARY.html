DIGIFLEX SALON SAAS · FRANCHISE PANEL DATA DICTIONARY

Franchise Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 2.7.0  |  Scope: Franchise Partner Workspace (`/franchise-portal/*` & `/admin/franchise`)  |  Key Domains: Territory Multi-Outlets Directory, Royalty Accruals & GST Settlements, Central HQ Supply Ordering, SOP Compliance Audits & Contracts Vault
Franchise Scoping Architecture: Every regional query, multi-outlet P&L consolidation, royalty calculation, and supply requisition is bound to the licensee's ID (WHERE franchise_partner_id = :partner_id).

1. Franchise Partner Identity & Master Agreements

Table: franchise_partners

UI Form Field / Column Database Column Name Data Type Constraints / Default Business Description
Partner Licensee ID id VARCHAR(64) PRIMARY KEY Partner ID (e.g. FP-001)
Franchise Legal Entity name VARCHAR(180) NOT NULL e.g. "Apex Wellness & Spa LLP"
Partner License Code code VARCHAR(30) UNIQUE, NOT NULL License Code (e.g. FP-IND-01)
Managing Director contact_person VARCHAR(120) NOT NULL Managing Principal
GSTIN Registration gstin VARCHAR(15) NOT NULL 15-character Legal GSTIN
Territory Region region VARCHAR(120) NOT NULL Exclusive Territory (e.g. "Indore & Malwa")
Agreement Validity Dates agreement_start_date, agreement_end_date DATE NOT NULL Contract Effective & Renewal Dates
Royalty Terms royalty_structure VARCHAR(100) DEFAULT '10% Gross Services + 5% Retail' Agreed Royalty Formula

2. Commercial Royalty Accruals & Settlement Invoices

Table: franchise_royalty_settlements

UI Field Database Column Data Type Constraints Calculation & Description
Settlement Month settlement_month VARCHAR(10) NOT NULL e.g. "AUG-2026"
Gross Service Sales gross_service_sales DECIMAL(12, 2) NOT NULL Total billed services across all franchise outlets
Calculated Service Royalty (10%) service_royalty_amount DECIMAL(12, 2) 10% of gross gross_service_sales * 0.10
Gross Retail Sales gross_retail_sales DECIMAL(12, 2) NOT NULL Total retail products sold
Calculated Retail Markup (5%) retail_royalty_amount DECIMAL(12, 2) 5% markup gross_retail_sales * 0.05
GST on Royalty (18%) gst_tax_amount DECIMAL(12, 2) 18% GST subtotal_royalty * 0.18
Total Payable to HQ total_payable_amount DECIMAL(12, 2) NOT NULL Total royalty liability invoice
Settlement Status payment_status VARCHAR(30) DEFAULT 'Pending Review' Up to Date, Pending Review, Overdue, Paid
Bank UTR Reference bank_transaction_ref VARCHAR(100) NULL NEFT/RTGS UTR Reference Code

3. Central HQ Supply Orders & Quality Audits

Table: franchise_supply_orders & franchise_compliance_audits

UI Field Database Column Data Type Constraints Description
Supply Order ID id VARCHAR(64) PRIMARY KEY B2B Order ID (e.g. FSO-2026-112)
Receiving Branch delivery_branch_id VARCHAR(64) FK → branches(id) Destination Franchise Outlet
Order Value (₹) total_order_amount DECIMAL(12, 2) NOT NULL Wholesale Supply Invoice Amount
Dispatch AWB Tracking dispatch_tracking_number VARCHAR(80) NULL Logistics Courier AWB Tracking
Audit Score % overall_score_pct DECIMAL(5, 2) NOT NULL Weighted Brand SOP & Hygiene Score
Compliance Grade compliance_grade VARCHAR(10) NOT NULL A+ (Excellent), A (Compliant), B (Action Req)
