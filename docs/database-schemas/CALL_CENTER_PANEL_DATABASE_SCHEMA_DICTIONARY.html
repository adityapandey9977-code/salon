DIGIFLEX SALON SAAS · CALL CENTER TELEPHONY DATA DICTIONARY

Call Center Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 3.0.0  |  Scope: Call Center Concierge Desk (`/call-center/*`)  |  Key Domains: CTI Telephony Inbound Screen-Pops, Cross-Branch Booking Dispatch, Telephony Call Logs & Audio Vault, Inquiries & Support Tickets, Outbound Lapsed Client Rebooking Queue
Central Telephony Dispatch Architecture: Instant CTI screen-pops matching incoming phone numbers to full CRM profiles (favourite stylists, VIP wallet balance, chemical allergies) with multi-branch calendar availability dispatch.

1. Inbound CTI Telephony & Agent Status

Table: call_center_agents

UI Field / Metric Database Column Data Type Constraints Business Description
Agent ID id VARCHAR(64) PRIMARY KEY Agent Identifier (e.g. AGT-001)
Agent Name agent_name VARCHAR(120) NOT NULL Concierge Representative
SIP Extension # telephony_extension VARCHAR(20) UNIQUE, NOT NULL Softphone / WebRTC Extension
CTI Provider telephony_provider VARCHAR(40) DEFAULT 'Exotel' Exotel, Twilio, Knowlarity
Agent Real-Time Status agent_status VARCHAR(30) DEFAULT 'Available' Available, On Call, Wrap-Up, Break

2. Inbound Screen-Pop Caller CRM Dossier

Table: clients & appointments

Screen-Pop Element Database Column / Query Data Type Description
Caller Phone Number clients.mobile_phone VARCHAR(20) Inbound caller ID
Customer Name first_name, last_name VARCHAR(80) Client Full Name
VIP Tier Badge vip_tier VARCHAR(30) Bronze, Silver, Gold, Diamond VIP
Prepaid Wallet Balance wallet_balance DECIMAL(12, 2) Available advance credit (₹)
Chemical Allergies Notes allergies_notes TEXT Critical contraindications (e.g. Ammonia)

3. Telephony Call Audio Logs & Dispositions

Table: telephony_call_logs

UI Field Database Column Data Type Constraints Description
Call Log ID id VARCHAR(64) PRIMARY KEY Call Session (e.g. CALL-20260825-081)
Handling Agent agent_id VARCHAR(64) FK → call_center_agents(id) Attending Executive
Call Start Timestamp call_start_time TIMESTAMPTZ NOT NULL Call connection timestamp
Call Duration (Secs) duration_seconds INTEGER NOT NULL Conversation length
Audio Recording URL recording_audio_url TEXT NULL S3 Audio Recording Playback Link
Call Intent Disposition disposition_category VARCHAR(60) NOT NULL Appointment Booked, Reschedule, Inquiry, Complaint
Resulting Booking resulting_appointment_id VARCHAR(64) FK → appointments(id) Converted Booking Link

4. Customer Support Tickets & Outbound Rebooking Queue

Table: customer_support_tickets & outbound_campaign_leads

UI Field Database Column Data Type Constraints Description
Support Ticket ID id VARCHAR(64) PRIMARY KEY Ticket ID (e.g. TCK-2026-042)
Affected Branch branch_id VARCHAR(64) FK → branches(id) Salon outlet involved
Issue Classification issue_category VARCHAR(60) NOT NULL Service Quality, Billing, Allergy Reaction
SLA Priority priority_level VARCHAR(20) DEFAULT 'Medium' Low, Medium, High, Critical
Compensation Credit (₹) compensation_credit DECIMAL(12, 2) DEFAULT 0.00 Goodwill wallet refund
Campaign Name campaign_name VARCHAR(120) NOT NULL e.g. "Lapsed 60-Day Rebooking"
Lead Conversion Status lead_status VARCHAR(30) DEFAULT 'Queued' Queued, No Answer, Booked / Converted
