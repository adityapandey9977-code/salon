DIGIFLEX SALON SAAS · STYLIST & THERAPIST DATA DICTIONARY

Stylist Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 3.1.0  |  Scope: Stylist Workspace & Tablet App (`/stylist-portal/*`)  |  Key Domains: Daily Chair Queue, Digital Colour Formula Cards, BOM Recipe Consumable Logging, Real-Time Commission Wallet & Before/After Portfolio Gallery
Stylist Scoping Architecture: Direct personal tablet & mobile app access scoped to the performing stylist ID (WHERE staff_id = :current_stylist_id) for managing client treatment formula cards, in-chair add-on upsells, and daily commission payouts.

1. Stylist Shift Roster & Daily Appointments Queue

Table: appointments & appointment_line_items

UI Field / Column Database Column Name Data Type Constraints / Default Business Description
Booking Reference id VARCHAR(64) PRIMARY KEY Booking ID (e.g. APT-2026-901)
Customer Client client_id VARCHAR(64) FK → clients(id) Customer Profile
Styling Station / Chair station_chair_number VARCHAR(30) NOT NULL Assigned Chair Station
Service Start & End scheduled_start_time, scheduled_end_time TIMESTAMPTZ NOT NULL Service appointment slot
Chair Lifecycle Status status VARCHAR(30) DEFAULT 'Confirmed' Confirmed, Arrived, In Service, Completed

2. Client Consultation Dossier & Digital Formula Cards

Table: client_treatment_formula_cards

Formula Card Field Database Column Name Data Type Description
Formula Card ID id VARCHAR(64) Formula Record (e.g. FORM-2026-081)
Base Hair Shade Level base_shade_level VARCHAR(50) e.g. "Level 4 Dark Brown (Virgin)"
Target Shade Level target_shade_level VARCHAR(50) e.g. "Level 7 Caramel Blonde Balayage"
Color Shade Formula primary_formula_sku VARCHAR(80) e.g. "Majirel 6.13 (45g)"
Oxidant Developer Ratio developer_volume_ratio VARCHAR(80) e.g. "20 Vol (60ml) · 1:1.5 Ratio"
Patch Test Status patch_test_cleared BOOLEAN Verified 24hr allergy clearance
Scalp Sensitivity Notes scalp_sensitivity_notes TEXT Contraindications & allergy notes

3. Stylist Commission Wallet, Tips & Target Progress

Table: staff_commission_ledger

UI Wallet Field Database Column / Query Data Type Description
Today's Commission SUM(commission_amount) WHERE DATE = TODAY DECIMAL(12, 2) Real-time computed daily commission (₹)
Today's Tips Collected SUM(invoices.tip_amount) DECIMAL(12, 2) Client gratuities attributed to stylist
MTD Billed Sales (₹) SUM(service_billed_amount + retail_billed_amount) DECIMAL(12, 2) Gross revenue generated on chair
Monthly Target % (revenue_billed / target_amount) * 100 DECIMAL(5, 2) Monthly sales target progress bar
Wallet Payout Status status VARCHAR(20) Accrued, Approved, Paid
