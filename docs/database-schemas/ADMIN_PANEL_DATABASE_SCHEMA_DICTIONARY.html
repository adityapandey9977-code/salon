DIGIFLEX SALON SAAS · ADMIN PANEL DATA DICTIONARY

Admin Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 2.5.0  |  Scope: Admin Panel (`/admin/*`)  |  Target Modules: Locations, Catalogue & BOM, Multi-Branch Inventory, Procurement & POs, Transfers, Stocktake Audits, Clients CRM, Staff & Commissions, Finance & GST, Franchise Governance
Mapping Standard: Every UI field, table column, modal form, filter dropdown, and action button in the Admin Panel web interface maps directly to relational database tables with strict foreign-key integrity.

1. Locations & Multi-Branch Desk (`/admin/locations`)

Table: branches (Branches Registry)

UI Form Field / Table Column Database Column Name Data Type Constraints / Default Business Purpose & Mapping
Branch ID id VARCHAR(64) PRIMARY KEY Unique Branch Code (e.g. BR-001)
Branch Name name VARCHAR(150) NOT NULL Registered Name (e.g. "Atelier Indrapuri Flagship")
Branch Code code VARCHAR(30) UNIQUE, NOT NULL System Prefix Code (e.g. ATL-IND-01)
Location Type type VARCHAR(30) NOT NULL Flagship, Lounge, Express, Franchise
Franchise Partner Assignment franchise_partner_id VARCHAR(64) NULL, FK → franchise_partners(id) Linked master franchise partner if Franchise-owned
City / Region city VARCHAR(80) NOT NULL City Name (e.g. "Bhopal", "Indore", "Pune")
Street Address address_street TEXT NOT NULL Physical premises address
Branch General Manager manager_name VARCHAR(120) NOT NULL Assigned General Manager
Contact Phone Number contact_phone VARCHAR(20) NOT NULL Client reception phone number
Working Hours Window working_hours_display VARCHAR(80) DEFAULT '09:00 AM - 09:00 PM' Operating shift display string
Branch Status status VARCHAR(20) DEFAULT 'Active' Active, Inactive, Under Renovation

2. Catalogue, Services & Recipe BOM (`/admin/catalogue`)

Table: services & service_recipes

UI Form Field / Table Column Database Column Name Data Type Constraints / Default Business Mapping
Service SKU ID id VARCHAR(64) PRIMARY KEY Service SKU ID (e.g. SRV-MAJ-613)
Service Title name VARCHAR(150) NOT NULL e.g. "Global Hair Colour - Majirel"
Category category_id VARCHAR(64) FK → service_categories(id) Hair, Skin, Aesthetics, Spa
Gender Applicability gender_target VARCHAR(20) DEFAULT 'Unisex' Female, Male, Unisex
Execution Duration base_duration_mins INTEGER NOT NULL Minutes on styling chair
Buffer Time buffer_time_mins INTEGER DEFAULT 10 Cleaning/Prep buffer
Base Price (Excl. Tax) base_price DECIMAL(12, 2) NOT NULL Base Selling Price (₹)
GST Tax Rate gst_rate_pct DECIMAL(5, 2) DEFAULT 18.00 18% standard GST

3. Inventory & Procurement Master Desk (`/admin/inventory`)

Table: products_master_skus (Master SKU Directory)

UI Form Field / Table Column Database Column Name Data Type Constraints / Default Description
Master SKU ID id VARCHAR(64) PRIMARY KEY Master SKU (e.g. SKU-MAJ-613)
Barcode / SKU Code sku_code VARCHAR(50) UNIQUE, NOT NULL Barcode scanned at POS/GRN
Product Full Name name VARCHAR(180) NOT NULL e.g. "L'Oréal Majirel Colour Tube - 6.13"
Item Classification item_type VARCHAR(30) NOT NULL Consumable (Backwash), Retail (Resale)
Packaging Unit measurement_unit VARCHAR(30) NOT NULL ml, gm, Tubes, Bottles, pcs
GST HSN Code hsn_code VARCHAR(20) NOT NULL 8-digit GST HSN (e.g. 33051090)
Maximum Retail Price (MRP) mrp_selling_price DECIMAL(12, 2) NOT NULL Client retail selling price
Base Purchase Cost default_purchase_cost DECIMAL(12, 2) NOT NULL Inward FIFO baseline cost

Table: suppliers, purchase_orders & purchase_returns_debit_notes

UI Form Field Database Column Name Data Type Constraints Description
Vendor Trading Name name VARCHAR(180) NOT NULL Legal Entity (e.g. "L'Oréal India")
Vendor GSTIN gstin VARCHAR(15) NOT NULL 15-character GSTIN
Credit Terms payment_terms VARCHAR(100) DEFAULT 'Net 30 Days' Settlement agreement
PO Total Payable total_payable_amount DECIMAL(12, 2) NOT NULL PO Gross Value (Incl. 18% GST)
PO Approval Status status VARCHAR(30) DEFAULT 'Pending Approval' Pending Approval, Approved, Fully Received
Debit Note Reference credit_note_ref VARCHAR(50) NOT NULL Reference (e.g. DN-2026-0881)
Return Reason reason VARCHAR(120) NOT NULL Damaged in Transit, Near Expiry Spoilage

Table: stock_transfers & stocktake_sessions

UI Field Database Column Data Type Constraints Description
Source Branch source_branch_id VARCHAR(64) FK → branches(id) Dispatch origin branch
Destination Branch destination_branch_id VARCHAR(64) FK → branches(id) Receiving branch
Box Seal Code seal_number VARCHAR(60) NOT NULL Tamper-evident seal number
Audit Methodology counting_methodology VARCHAR(40) DEFAULT 'Blind Count' Blind Count vs Visible Book Count
POS Freeze Status is_pos_frozen BOOLEAN DEFAULT TRUE Lockdown POS during stocktake
Net Variance (Units) variance_quantity INTEGER DEFAULT 0 Difference (Actual - Expected)
Net Variance Value variance_value DECIMAL(12, 2) DEFAULT 0.00 Net financial discrepancy loss/gain (₹)

4. Client CRM & POS Invoicing (`/admin/clients`, `/admin/finance`)

Table: clients & invoices

UI Field Database Column Data Type Constraints Description
Client Mobile Number mobile_phone VARCHAR(20) UNIQUE, NOT NULL Primary key for POS search lookup
Client Full Name first_name, last_name VARCHAR(80) NOT NULL Customer Given Name & Surname
VIP Tier Badge vip_tier VARCHAR(30) DEFAULT 'Regular' Bronze, Silver, Gold, Diamond VIP
Prepaid Wallet Balance wallet_balance DECIMAL(12, 2) DEFAULT 0.00 Account advance deposit (₹)
GST Tax Invoice # invoice_number VARCHAR(50) UNIQUE, NOT NULL Official GST Tax Invoice (e.g. INV-ATL-26-0881)
CGST / SGST / IGST cgst_amount, sgst_amount DECIMAL(12, 2) DEFAULT 0.00 State & Central GST (9% + 9%)
Gross Invoice Total total_payable_amount DECIMAL(12, 2) NOT NULL Final Bill Total (₹)
