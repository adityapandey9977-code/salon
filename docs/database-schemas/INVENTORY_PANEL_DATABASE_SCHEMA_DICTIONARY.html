DIGIFLEX SALON SAAS · INVENTORY SUPPLY CHAIN DATA DICTIONARY

Inventory Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 2.9.0  |  Scope: Inventory Controller Desk (`/admin/inventory` & `/inventory-controller/*`)  |  Key Domains: Master SKUs, FIFO Batches, Procurement POs, GRN Inwarding, Debit Notes, Inter-Branch Transfers, Recipe BOM Consumption Logs, Physical Blind Stocktake Sessions
Supply Chain Architecture: Full lifecycle tracking from central vendor procurement, FIFO batch lot allocation, tamper-sealed inter-branch logistics, automated BOM service consumable deductions, and blind-count stocktake discrepancy adjustments.

1. Master SKU Catalog & Multi-Branch Stock Ledgers

Table: products_master_skus & branch_stock_ledgers

UI Form Field / Column Database Column Name Data Type Constraints / Default Business Description
Master SKU ID id VARCHAR(64) PRIMARY KEY SKU ID (e.g. SKU-MAJ-613)
Barcode / EAN-13 sku_code VARCHAR(50) UNIQUE, NOT NULL Scanned Barcode
Product Name name VARCHAR(180) NOT NULL e.g. "L'Oréal Majirel Colour Tube - 6.13"
Classification item_type VARCHAR(30) NOT NULL Consumable (Backwash), Retail (Resale)
Packaging Unit measurement_unit VARCHAR(30) NOT NULL ml, gm, Tubes, Bottles, pcs
GST HSN Code hsn_code VARCHAR(20) NOT NULL 8-digit Tariff Code (e.g. 33051090)
On-Hand Physical Stock on_hand_quantity DECIMAL(10, 3) DEFAULT 0 Physical units in store
Available Stock Units available_quantity DECIMAL(10, 3) on_hand - allocated_reserved Net available for service/sale

2. Procurement POs, GRN & Purchase Returns Debit Notes

Table: purchase_orders & purchase_returns_debit_notes

UI Field Database Column Data Type Constraints Description
PO Reference Number po_number VARCHAR(40) UNIQUE, NOT NULL Official PO # (e.g. PO-2026-081)
Supplier Vendor supplier_id VARCHAR(64) FK → suppliers(id) Approved Vendor
Delivery Branch delivery_branch_id VARCHAR(64) FK → branches(id) Receiving Branch
Total Payable Amount total_payable_amount DECIMAL(12, 2) NOT NULL Gross Order Total with 18% GST
PO Approval Status status VARCHAR(30) DEFAULT 'Pending Approval' Pending Approval, Approved, Fully Received
Debit Note Reference credit_note_ref VARCHAR(50) NOT NULL Debit Note # (e.g. DN-2026-0881)
Return Reason Classification reason VARCHAR(120) NOT NULL Damaged in Transit, Near Expiry Spoilage

3. Inter-Branch Transfers & Blind Physical Stocktake Audits

Table: stock_transfers & stocktake_sessions

UI Field Database Column Data Type Constraints Description
Transfer ID id VARCHAR(64) PRIMARY KEY Transfer ID (e.g. TR-2026-042)
Source / Dest Branch source_branch_id, destination_branch_id VARCHAR(64) FK → branches(id) Dispatch & Receiving Outlets
Carrier & Box Seal # carrier, seal_number VARCHAR(100) NOT NULL Carrier Mode & Tamper-Evident Seal
Counting Methodology counting_methodology VARCHAR(40) DEFAULT 'Blind Count' Blind Count vs Visible Book Count
POS Freeze Status is_pos_frozen BOOLEAN DEFAULT TRUE Lockdown POS during stocktake
Net Variance Units variance_quantity INTEGER DEFAULT 0 Difference (Actual - Expected)
Net Financial Impact (₹) variance_value DECIMAL(12, 2) DEFAULT 0.00 Net loss/gain write-off value
