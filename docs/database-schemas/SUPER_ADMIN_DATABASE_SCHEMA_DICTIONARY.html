DIGIFLEX SALON SAAS · TECHNICAL DATA ARCHITECTURE

Super Admin Panel Database Schema & Entity Dictionary

Specification Version: 2.4.0  |  Database Target: PostgreSQL 15+ / Distributed SQL  |  Architecture Scope: Super Admin, Franchise Governance, Multi-Branch Stock, POS & Recipe BOM
Design Standard: Strict referential foreign-key integrity, multi-tenant branch partitioning, FIFO batch inventory tracking, and Indian GST (CGST/SGST/IGST) monetary precision.

1. Brand & Identity Core Domain

Table: brands (Tenant Master)

Field Name Data Type Constraints Mapping & Business Description
id VARCHAR(64) PRIMARY KEY Brand UUID / Business Identifier (e.g. BRD-001)
name VARCHAR(150) NOT NULL Brand Trading Name (e.g. "Atelier Luxury Salons")
legal_name VARCHAR(200) NOT NULL Registered Legal Corporate Entity Name
gstin VARCHAR(15) UNIQUE 15-character Central GSTIN
pan_number VARCHAR(10) NOT NULL Corporate Income Tax PAN
headquarters_address TEXT NOT NULL HQ Physical Office Address
contact_email VARCHAR(150) NOT NULL Central Corporate Inbox Email
contact_phone VARCHAR(20) NOT NULL Central Front Office Direct Phone
currency VARCHAR(3) DEFAULT 'INR' Base Currency ISO-4217
status VARCHAR(20) DEFAULT 'Active' Active, Suspended, Trial

Table: branches (Multi-Branch Outlets)

Field Name Data Type Constraints Mapping & Business Description
id VARCHAR(64) PRIMARY KEY Branch Identifier (e.g. BR-001)
brand_id VARCHAR(64) FK → brands(id) Owning Brand Tenant
name VARCHAR(150) NOT NULL Outlet Name (e.g. "Atelier Indrapuri Flagship")
code VARCHAR(30) UNIQUE, NOT NULL Branch Code (e.g. ATL-IND-01)
type VARCHAR(30) NOT NULL Flagship, Lounge, Express, Franchise
franchise_partner_id VARCHAR(64) FK → franchise_partners(id) Assigned Franchise Partner if Franchise-owned
city VARCHAR(80) NOT NULL City Location (e.g. Bhopal, Indore, Pune)
manager_name VARCHAR(120) NOT NULL General Manager in Charge
contact_phone VARCHAR(20) NOT NULL Front Desk Phone Number
working_hours VARCHAR(80) DEFAULT '09:00 AM - 09:00 PM' Operating Shift Window
chair_count INTEGER DEFAULT 10 Total Styling Stations / Treatment Beds

2. Franchise & Master Partner Network

Table: franchise_partners

Field Name Data Type Constraints Mapping & Business Description
id VARCHAR(64) PRIMARY KEY Franchise Partner ID (e.g. FP-001)
company_name VARCHAR(180) NOT NULL Partner Entity (e.g. "Apex Wellness & Spa LLP")
code VARCHAR(30) UNIQUE, NOT NULL Partner License Code (e.g. FP-IND-01)
contact_person VARCHAR(120) NOT NULL Managing Director / Principal
territory_region VARCHAR(120) NOT NULL Exclusive Territory (e.g. "Indore & Malwa")
agreement_status VARCHAR(30) DEFAULT 'Active' Active, Expiring Soon, Under Renewal
royalty_percentage DECIMAL(5, 2) DEFAULT 10.00 Gross Services Royalty Accrual %

3. Catalogue, Services & Recipe BOM (Bill of Materials)

Table: services & service_recipes

Field Name Data Type Constraints Mapping & Business Description
id VARCHAR(64) PRIMARY KEY Service SKU ID (e.g. SRV-COL-613)
name VARCHAR(150) NOT NULL Service Display Name (e.g. "Global Hair Colour")
base_duration_mins INTEGER NOT NULL Service Execution Time in Minutes
buffer_time_mins INTEGER DEFAULT 10 Stylist Prep & Sanitization Buffer
base_price DECIMAL(12, 2) NOT NULL Standard Base Rate (Excl. GST)
gst_rate_percentage DECIMAL(5, 2) DEFAULT 18.00 Applicable GST Rate (18%)
Recipe Field Data Type Constraints Recipe BOM Description
service_id VARCHAR(64) FK → services(id) Target Salon Service
product_sku_id VARCHAR(64) FK → products_master_skus(id) Dispensed Product Consumable
standard_quantity DECIMAL(10, 3) NOT NULL Exact Quantity Dispensed (e.g. 45.000)
measurement_unit VARCHAR(30) NOT NULL Standard Unit (ml, gm, Tubes, Scoops, Pods)
cost_per_service DECIMAL(12, 2) NOT NULL Computed FIFO Ingredient Cost Price

4. Master Inventory, SKUs & Multi-Location Stock Ledgers

Table: products_master_skus & branch_stock_ledgers

Field Name Data Type Constraints Mapping & Description
id VARCHAR(64) PRIMARY KEY Master SKU ID (e.g. SKU-MAJ-613)
sku_code VARCHAR(50) UNIQUE, NOT NULL Barcode / Identifier
name VARCHAR(180) NOT NULL Product Name (e.g. "L'Oréal Majirel Colour Tube")
item_type VARCHAR(30) NOT NULL Consumable (Backwash), Retail (Resale)
measurement_unit VARCHAR(30) NOT NULL Units (ml, gm, Tubes, Bottles, pcs)
hsn_code VARCHAR(20) NOT NULL 8-Digit GST HSN Code
mrp_selling_price DECIMAL(12, 2) NOT NULL Maximum Retail Price (MRP)
default_purchase_cost DECIMAL(12, 2) NOT NULL Standard Base FIFO Inwarding Cost

5. Procurement, Suppliers, POs & Debit Notes

Table: purchase_orders & purchase_returns_debit_notes

Field Name Data Type Constraints Description
id VARCHAR(64) PRIMARY KEY Purchase Order ID (e.g. PO-2026-081)
po_number VARCHAR(40) UNIQUE, NOT NULL PO Reference Number
supplier_id VARCHAR(64) FK → suppliers(id) Selected Vendor Partner
delivery_branch_id VARCHAR(64) FK → branches(id) Destination Salon Branch
total_payable_amount DECIMAL(12, 2) NOT NULL Gross Order Total (Incl. 18% GST)
status VARCHAR(30) DEFAULT 'Pending Approval' Pending Approval, Approved, Fully Received

6. Stock Transfers & Physical Stocktake Discrepancies

Table: stock_transfers & stocktake_sessions

Field Name Data Type Constraints Description
id VARCHAR(64) PRIMARY KEY Transfer ID (e.g. TR-2026-042)
source_branch_id VARCHAR(64) FK → branches(id) Dispatch Origin Outlet
destination_branch_id VARCHAR(64) FK → branches(id) Receiving Destination Outlet
carrier_logistics_mode VARCHAR(100) NOT NULL Transport Carrier Mode
container_seal_number VARCHAR(60) NOT NULL Tamper-Evident Box Seal Code
status VARCHAR(30) DEFAULT 'Requested' Requested, In Transit, Received

7. Client CRM, POS Tax Invoicing & Staff Commissions

Table: clients & invoices

Field Name Data Type Constraints Description
id VARCHAR(64) PRIMARY KEY Client CRM ID (e.g. CLT-001)
mobile_phone VARCHAR(20) UNIQUE, NOT NULL Primary Key for Front-Desk POS Lookup
first_name VARCHAR(80) NOT NULL Client Given Name
vip_tier VARCHAR(30) DEFAULT 'Regular' Bronze, Silver, Gold, Black Diamond VIP
wallet_balance DECIMAL(12, 2) DEFAULT 0.00 Prepaid Account Wallet Balance
