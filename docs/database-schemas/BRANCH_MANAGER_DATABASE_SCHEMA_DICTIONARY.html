DIGIFLEX SALON SAAS · BRANCH MANAGER DATA DICTIONARY

Branch Manager Panel Database Schema & UI Field Mapping Dictionary

Specification Version: 2.6.0  |  Scope: Branch Manager Workspace (`/branch-manager/*`)  |  Operational Modules: Live Chair Matrix, Appointment Diary, POS Billing & Split Tenders, Recipe Consumable Auto-Deduction, Local Shelf Stock & GRN Inwarding, Daily Staff Rosters & EOD Cash Till Reconciliation
Branch Scoping Architecture: Every operation, query, station assignment, stock deduction, and cash drawer balance is strictly scoped to the manager's assigned branch (WHERE branch_id = :current_branch_id).

1. Appointment Diary, Calendar & Chair Matrix

Table: appointments & appointment_line_items

UI Form Field / Column Database Column Name Data Type Constraints / Default Business Description
Booking Reference id VARCHAR(64) PRIMARY KEY Booking ID (e.g. APT-2026-901)
Branch Scope branch_id VARCHAR(64) NOT NULL, FK → branches(id) Manager's salon branch
Client Customer client_id VARCHAR(64) NOT NULL, FK → clients(id) Selected Client
Assigned Stylist staff_id VARCHAR(64) NOT NULL, FK → staff_profiles(id) Performing Specialist
Station / Chair Number station_chair_number VARCHAR(30) NOT NULL e.g. "Chair 04", "Suite 02"
Start & End Timestamps scheduled_start_time, scheduled_end_time TIMESTAMPTZ NOT NULL Service appointment slot
Appointment Status status VARCHAR(30) DEFAULT 'Confirmed' Confirmed, Arrived, In Service, Completed, Cancelled

2. Point of Sale (POS), Split Tenders & Recipe Consumable Auto-Deduction

Table: invoices & invoice_payments

UI Field Database Column Data Type Constraints Description
GST Invoice # invoice_number VARCHAR(50) UNIQUE, NOT NULL Tax Invoice (e.g. INV-ATL-26-0881)
Taxable Base Amount subtotal_amount DECIMAL(12, 2) NOT NULL Services & retail products total
GST (CGST 9% + SGST 9%) cgst_amount, sgst_amount DECIMAL(12, 2) DEFAULT 0.00 Indian GST breakdown
Stylist Tip Gratuity tip_amount DECIMAL(12, 2) DEFAULT 0.00 Tip attributed to stylist
Gross Total Payable total_payable_amount DECIMAL(12, 2) NOT NULL Net checkout total (₹)
Tender Modes payment_mode VARCHAR(30) NOT NULL Cash, Card, UPI / QR, Wallet, Voucher

Table: stock_consumption_logs (Automatic Backwash Ingredient Deduction)

Field Name Data Type Constraints Auto-Triggered Business Description
invoice_id VARCHAR(64) FK → invoices(id) Triggering completed invoice
service_id VARCHAR(64) FK → services(id) Executed service
product_sku_id VARCHAR(64) FK → products_master_skus(id) Consumed backwash product SKU
batch_number VARCHAR(60) NOT NULL Lot number deducted via FIFO queue
standard_recipe_qty DECIMAL(10, 3) NOT NULL Theoretical BOM standard (e.g. 45.000 ml)
actual_dispensed_qty DECIMAL(10, 3) NOT NULL Actual dispensed quantity (e.g. 48.000 ml)
variance_qty DECIMAL(10, 3) GENERATED ALWAYS AS (actual_dispensed_qty - standard_recipe_qty) Wastage / over-consumption variance

3. Local Shelf Stock & Goods Receipt (GRN)

Table: branch_stock_ledgers & stock_transfers

UI Field Database Column Data Type Constraints Description
On-Hand Physical Units on_hand_quantity DECIMAL(10, 3) DEFAULT 0 Units on shelf/backwash
Available Stock Units available_quantity DECIMAL(10, 3) GENERATED ALWAYS AS (on_hand_quantity - allocated_reserved_qty) Net available for service/retail
Safety Stock Alert Level safety_stock_threshold INTEGER DEFAULT 5 Branch reorder trigger point
GRN Received Units received_quantity INTEGER NOT NULL Counted units upon unboxing
Tamper Seal Verified is_seal_intact BOOLEAN DEFAULT TRUE Dual-custody box seal verification

4. Staff Roster & Daily Stylist Commissions

Table: staff_attendance_logs & staff_commission_ledger

UI Field Database Column Data Type Constraints Description
Staff Member staff_id VARCHAR(64) FK → staff_profiles(id) Stylist / Aesthetician
Clock-In & Clock-Out clock_in_time, clock_out_time TIMESTAMPTZ NOT NULL Daily floor shift attendance
Attendance Status status VARCHAR(20) DEFAULT 'Present' Present, Late Check-In, Half Day
Daily Commission Earned commission_amount DECIMAL(12, 2) NOT NULL DEFAULT 0.00 Computed stylist commission (₹)

5. Daily Cash Drawer & End-of-Day (EOD) Till Reconciliation

Table: cash_drawer_sessions

UI Settlement Report Field Database Column Name Data Type Constraints / Calculation Description
Session ID id VARCHAR(64) PRIMARY KEY Till Session ID (e.g. TILL-20260825-01)
Opening Cash Float opening_cash_float DECIMAL(12, 2) NOT NULL DEFAULT 5000.00 Starting cash in register
Cash Sales Total total_cash_sales DECIMAL(12, 2) NOT NULL DEFAULT 0.00 Sum of Cash tender invoices
Card & UPI Digital Total total_card_sales, total_upi_sales DECIMAL(12, 2) NOT NULL DEFAULT 0.00 EDC machine batch & UPI QR total
Petty Cash Payouts total_cash_payouts DECIMAL(12, 2) DEFAULT 0.00 Branch miscellaneous expenses
Expected Cash in Till expected_closing_cash DECIMAL(12, 2) opening_cash_float + total_cash_sales - total_cash_payouts Theoretical cash in register
Physical Hand-Counted Cash actual_closing_cash DECIMAL(12, 2) NOT NULL Physical notes counted at EOD
Cash Variance (Over/Short) cash_variance_delta DECIMAL(12, 2) actual_closing_cash - expected_closing_cash Discrepancy (+ / -)
Manager EOD Sign-off closed_by_user_id VARCHAR(64) FK → users(id) Manager closing the day
