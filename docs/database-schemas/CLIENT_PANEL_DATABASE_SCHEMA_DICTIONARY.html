DIGIFLEX SALON SAAS · CLIENT MOBILE & WEB APP DATA DICTIONARY

Client Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 3.2.0  |  Scope: Customer Mobile App & Self-Service Web Portal (`apps/customer-mobile` & `/client-portal/*`)  |  Key Domains: Service Discovery, Multi-Service Cart Booking, Live QR Check-In, Prepaid Wallet & Package Vouchers, Downloadable Tax Invoices, 5-Star Ratings & Stylist Digital Tipping
Client Scoping Architecture: Direct authenticated customer access scoped to the client's account ID (WHERE client_id = :current_client_id) for managing personal appointments, active package vouchers, wallet balances, and treatment history.

1. Client Profile & Preferences

Table: clients

UI Form Field / Profile Element Database Column Name Data Type Constraints Business Description
Customer ID id VARCHAR(64) PRIMARY KEY Client Record (e.g. CLT-001)
Primary Mobile Phone mobile_phone VARCHAR(20) UNIQUE, NOT NULL OTP Authentication Login Key
Customer Name first_name, last_name VARCHAR(80) NOT NULL Given Name & Surname
VIP Tier Badge vip_tier VARCHAR(30) DEFAULT 'Regular' Bronze, Silver, Gold, Diamond VIP
Prepaid Wallet Balance (₹) wallet_balance DECIMAL(12, 2) DEFAULT 0.00 Account advance credit
Chemical Allergies Notes allergies_notes TEXT NULL Scalp & skin contraindications

2. Service Discovery & Multi-Service Cart Booking

Table: appointments & appointment_line_items

UI Booking Step Database Column Data Type Constraints Description
Booking Reference id VARCHAR(64) PRIMARY KEY Booking ID (e.g. APT-2026-901)
Selected Salon Outlet branch_id VARCHAR(64) FK → branches(id) Target Salon Branch
Selected Specialist staff_id VARCHAR(64) FK → staff_profiles(id) Stylist or "Any Available"
Selected Time Slot scheduled_start_time TIMESTAMPTZ NOT NULL Appointment Start Slot
Total Cart Amount (₹) total_estimated_amount DECIMAL(12, 2) NOT NULL Total value of services
Booking Status status VARCHAR(30) DEFAULT 'Confirmed' Confirmed, In Service, Completed

3. Digital Wallet, Package Vouchers & Reviews

Table: client_package_subscriptions & service_reviews_ratings

UI Component Database Column Data Type Constraints Description
Package Plan Name packages_memberships.name VARCHAR(150) NOT NULL e.g. "Royal Bridal Glow Package"
Remaining Sessions remaining_sessions INTEGER NOT NULL Available sessions to redeem
Package Expiry Date expiry_date DATE NOT NULL Validity deadline
Star Rating Score star_rating SMALLINT 1 to 5 Stars Service experience score
Stylist Tip Gratuity (₹) stylist_tip_amount DECIMAL(12, 2) DEFAULT 0.00 Digital tip paid to stylist via UPI/Card
