DIGIFLEX SALON SAAS · FINANCE & HR DATA DICTIONARY

Finance & HR Panel Module Database Schema & UI Field Mapping Dictionary

Specification Version: 2.8.0  |  Scope: Finance & Human Resources Workspace (`/finance-hr/*` & `/admin/finance`, `/admin/staff`)  |  Key Domains: General Ledger, GST Tax Returns (GSTR-1/3B), Accounts Payable, Employee KYC Vault, Monthly Payroll Runs, Stylist Commission Engine, PF/ESI/TDS/PT Deductions
Finance & Payroll Precision Architecture: Double-entry journal vouchers with balanced debits and credits, statutory tax ledgers for GSTR-1/3B filings, and automated payroll runs combining basic pay, stylist commissions, and Indian statutory deductions (PF 12%, ESI 0.75%, TDS, PT).

1. General Ledger, Chart of Accounts & Financial Journals

Table: chart_of_accounts & journal_vouchers

UI Form Field / Column Database Column Name Data Type Constraints / Default Business Description
Account Code account_code VARCHAR(30) PRIMARY KEY Account Code (e.g. 1001-CASH, 4001-REV-SRV)
Account Title account_name VARCHAR(150) NOT NULL e.g. "Salon Services Revenue", "Vendor Cost of Goods"
Account Category account_category VARCHAR(40) NOT NULL Asset, Liability, Equity, Revenue, Expense
Voucher Number voucher_number VARCHAR(40) UNIQUE, NOT NULL Journal Voucher Reference (e.g. JV-2026-0881)
Total Debits & Credits total_debit, total_credit DECIMAL(14, 2) NOT NULL Double-Entry Balance Verification

2. GST Invoicing, Tax Ledgers & Statutory Compliance

Table: gst_tax_ledgers

UI Field Database Column Data Type Constraints Description
HSN / SAC Code hsn_sac_code VARCHAR(20) NOT NULL 999721 (Services) or 33051090 (Goods)
Taxable Base Value taxable_value DECIMAL(12, 2) NOT NULL Net base amount (Excl. Tax)
CGST / SGST (9% + 9%) cgst_amount, sgst_amount DECIMAL(12, 2) DEFAULT 0.00 Central & State GST components
Input Tax Credit (ITC) itc_claimed_amount DECIMAL(12, 2) DEFAULT 0.00 GST credit eligible from vendor purchases
Net GST Payable net_tax_payable DECIMAL(12, 2) (CGST + SGST + IGST) - ITC Net GST tax due to Government
