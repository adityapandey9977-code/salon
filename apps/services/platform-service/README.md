# Platform Service

## Responsibilities
- SaaS Multi-Tenant provisioning workflow
- Subscription plans catalog & pricing tiers (Starter, Growth, Enterprise)
- Tenant subscription lifecycle, trial expiry & renewals
- Granular feature flags & tenant module entitlements
- Custom domain routing & SSL certificate mapping
- White-label customization (custom logos, tenant colors, theme tokens)
- Platform-wide operational configuration
- Domain events: `TenantCreated`, `TenantActivated`

## Port
`5011`

## Logical Database
`platform_db`
