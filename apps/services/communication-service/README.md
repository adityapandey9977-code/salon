# Communication Service

## Responsibilities
- Centralized notification dispatch (WhatsApp, SMS, Email, Push)
- Message templates with dynamic interpolation variables
- Marketing campaigns & broadcast scheduling
- Telephony call logs & recording metadata
- Agent Call Center session routing
- Delivery status tracking & retry logic
- NOTE: Does NOT duplicate CRM or Booking entities. Call Center communicates with Customer Service and Booking Service.

## Port
`5010`

## Logical Database
`communication_db`
