# Reporting Service

## Responsibilities
- Real-time Analytics Projections & Business Intelligence
- Executive Dashboard KPIs (gross revenue, avg ticket size, utilization rates)
- Scheduled & ad-hoc report generation (GST GSTR-1, P&L, inventory valuation)
- Immutable, append-only audit trail write worker & query APIs
- NOTE: Audit storage is logically isolated and append-only.
